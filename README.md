# 3分勇者 プライバシーポリシー

最終更新日：2026年10月16日

『3分勇者』（以下「本アプリ」）では、オンラインランキング機能を提供するため、以下の情報を取り扱います。

## 1. 取得する情報

本アプリでは、オンラインランキングへの記録登録時に、以下の情報を取得・保存する場合があります。

- プレイヤーが入力したプレイヤー名
- ゲームのランキング記録（魔王討伐時の消費G、クリアタイム、記録日時等）

本アプリでは、ランキング機能の利用にあたり、氏名、住所、電話番号、メールアドレス等の入力を求めません。

## 2. 利用目的

取得した情報は、オンラインランキングの作成、表示、順位判定およびランキング機能の適切な運営のために利用します。

## 3. 外部サービスの利用

本アプリでは、オンラインランキング機能の提供およびデータ保存のため、Supabaseを利用しています。ランキングに必要な情報は、同サービスを通じて送信・保存される場合があります。

## 4. 第三者への提供

取得した情報を、法令に基づく場合を除き、上記の目的以外で第三者に販売または提供することはありません。

なお、ランキングに登録されたプレイヤー名およびゲーム記録は、ランキング機能の性質上、他の利用者に表示される場合があります。

## 5. 個人情報の入力について

プレイヤー名には、本名、住所、電話番号、メールアドレスなど、個人を特定できる情報を入力しないでください。

## 6. プライバシーポリシーの変更

本ポリシーは、本アプリの機能変更、利用サービスの変更、法令等への対応に伴い、必要に応じて変更する場合があります。

## 7. お問い合わせ

本アプリおよび本ポリシーに関するお問い合わせは、Google Playストアに掲載されている開発者の連絡先までお願いいたします。
